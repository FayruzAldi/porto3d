=====================================================
FOLDER MODEL 3D (.GLB)
=====================================================

Tempatkan file model 3D kustom Anda di sini dengan nama:
scene.glb

Panduan:
1. Export model ruangan/meja dari Blender dalam format .glb (glTF Binary).
2. Simpan di folder ini: public/models/scene.glb
3. Di website, buka aplikasi "Settings (Control Panel)", lalu centang:
   "Load Custom Model (.glb di /models/scene.glb)"
   Atau ubah default useCustomModel: true di src/stores/portfolioStore.ts.
